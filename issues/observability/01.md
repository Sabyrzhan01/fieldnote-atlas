# [Observability] Isolate development and production

## Goal

Create one environment-specific Compose project per release. Document private configuration, distinct PostgreSQL credentials and separate persistent volumes.

## Acceptance criteria

- [ ] Restart both projects and verify the note data survives.
- [ ] Create a note in development and verify production does not see it.
- [ ] Attach runtime evidence and link the implementation PR.
