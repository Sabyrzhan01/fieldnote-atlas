# [Observability] Export application signals over OTLP

## Goal

Instrument FastAPI and SQLAlchemy and export structured application logs. Route the three OTLP signals to Prometheus, Loki and Tempo via a Collector.

## Acceptance criteria

- [ ] Verify service, environment and digest on the emitted data.
- [ ] Locate a failed request log and correlate it to a request or database trace.
- [ ] Attach runtime evidence and link the implementation PR.
