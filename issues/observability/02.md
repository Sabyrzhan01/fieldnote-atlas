# [Observability] Publish and promote immutable releases

## Goal

Validate main with CI, publish the smoke-tested image to GHCR, then deploy development and record its verified digest. Add a manual promotion job and digest rollback.

## Acceptance criteria

- [ ] Compare the development and production API versions after manual promotion.
- [ ] Verify a wrong digest is rejected and a failed deployment restores its last good image.
- [ ] Attach runtime evidence and link the implementation PR.
