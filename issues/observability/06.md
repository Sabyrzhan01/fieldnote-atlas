# [Observability] Analyze incidents with an AI responder

## Goal

Authenticate incoming webhook events, query all three signal stores, call OpenAI for structured advice and store reports durably.

## Acceptance criteria

- [ ] Verify unauthorized calls are rejected and a repeated event results in one stored report.
- [ ] Verify a live alert produces an analyzed report containing evidence and actionable advice.
- [ ] Attach runtime evidence and link the implementation PR.
