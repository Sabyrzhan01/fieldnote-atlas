# [Observability] Exercise alerting and recovery

## Goal

Configure four Prometheus rules and an authenticated Alertmanager route. Add a repeatable development drill for server errors, latency and unavailability.

## Acceptance criteria

- [ ] Confirm all four alerts fire during the drill.
- [ ] Confirm the rules clear after service recovery and Alertmanager sends resolved events.
- [ ] Attach runtime evidence and link the implementation PR.
