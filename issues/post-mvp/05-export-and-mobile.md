# Post-MVP: Export and small-screen research workflow

## Goal
Researchers can take their evidence archive outside the desktop app and review it on a small screen.

## Acceptance criteria
- [ ] Export produces a valid UTF-8 JSON or CSV file with stable fields and tags.
- [ ] Export respects the chosen collection filter.
- [ ] At 390px viewport width, search, collection selection, note reading, and create remain usable.
- [ ] Keyboard focus and accessible labels remain visible on the narrow layout.

## Out of scope
- Native mobile applications and live tile licensing.

## Constraints
- Keep export formats documented and test representative special characters.
