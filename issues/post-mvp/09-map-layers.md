# Post-MVP: Map layers and accessible legend

## Goal
Researchers can interpret evidence categories and geographic context without mistaking the illustrative atlas for precise GIS data.

## Acceptance criteria
- [ ] A visible legend explains symbols and observation kinds.
- [ ] Layer visibility toggles do not delete or mutate observations.
- [ ] Selection and counts reflect visible layers and active filters.
- [ ] UI discloses that initial coordinates are approximate/illustrative.
- [ ] Layer behavior works with keyboard navigation and browser regression coverage.

## Out of scope
- Licensed basemaps, routing, geocoding, and spatial analysis.

## Constraints
- Keep the default map self-contained; avoid external tile requests.
