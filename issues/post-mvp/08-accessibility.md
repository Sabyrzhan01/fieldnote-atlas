# Post-MVP: Accessible map and evidence navigation

## Goal
Researchers can use the atlas without relying on pointer input or visual-only cues.

## Acceptance criteria
- [ ] Core controls expose accessible names, roles, and visible focus.
- [ ] Map pins have a keyboard-accessible equivalent list with identical selection behavior.
- [ ] Selection, validation, and save feedback are announced without stealing focus.
- [ ] Contrast and reduced-motion checks are documented.
- [ ] Automated accessibility checks and a keyboard-only walkthrough are recorded.

## Out of scope
- Certification claims or guarantees for every assistive technology.

## Constraints
- Use semantic HTML and include manual verification notes.
