# Fieldnote Atlas

A visual field-research archive for observations, interviews, artifacts, and place-based stories.

The complete source tree, including all Markdown project documents and the runnable app, is in [`fieldnote-atlas-source.zip`](fieldnote-atlas-source.zip). Download and extract it, then run `python3 server.py` inside the extracted `fieldnote-atlas` folder. Open `http://127.0.0.1:8091/`; add `?api=1` for the SQLite API.

The combined Markdown documentation is available in [`PROJECT-DOCUMENTATION.md`](PROJECT-DOCUMENTATION.md). The 14 groomed MVP issue drafts are under `issues/mvp/` inside the source archive.
