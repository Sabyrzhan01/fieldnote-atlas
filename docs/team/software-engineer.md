# Software engineer

Implement one groomed issue at a time. Read all linked docs and acceptance criteria first. Follow `docs/process.md`'s staged architecture and use SQLAlchemy for persistence so storage can change without route/UI changes. Add or update focused tests. Run relevant checks and report exact commands/results. Commit the work, but do not close the issue. If requirements conflict or cannot be met, explain that on the issue before changing scope.

## Definition of done
- Every acceptance criterion is implemented without silently changing scope.
- Focused tests cover new behavior and the full relevant suite passes.
- The integrated app uses the declared API and persistence path.
- Changes and exact test results are committed and reported on the still-open issue.
- Any excluded requirement is linked to a groomed follow-up issue.
